# Plan de Ejecución — SGLD

- [ ] **Fase 0: Base** — Repositorio, Docker, settings, estructura de carpetas, healthcheck y tests iniciales.
- [ ] **Fase 1: Cuentas** — Modelo de usuario custom, autenticación por email, roles, matriz de permisos y seed de usuarios.
- [ ] **Fase 2: Docentes** — Modelo de docentes, CRUD completo, asignaturas, foto, búsqueda avanzada y dashboard inicial.
- [ ] **Fase 3: Documentos** — Categorías, carga de archivos, previsualización protegida, estados y soft delete.
- [ ] **Fase 4: OCR** — Pipeline local con Tesseract, extracción de metadatos, confianza, bandeja de entrada y tareas asíncronas.
- [ ] **Fase 5: Validación y Alertas** — Cola de revisión (aprobar/rechazar), jobs de vencimiento y notificaciones por digest.
- [ ] **Fase 6: Auditoría y Reportes** — Registro inmutable, diff de cambios, exportaciones CSV y constancia imprimible en PDF.
- [ ] **Fase 7: Endurecimiento** — Suite de tests completa, validación de seguridad, scripts de backup/restore y README definitivo.
